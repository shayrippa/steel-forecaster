# ניהול הוצאות – Google Sheets

מערכת שהופכת את דפי הפירוט של **כאל** (PDF) ו**ישראכרט** (אקסל) לתמונת הוצאות מסודרת: סיווג לקטגוריות, ירוק/צהוב/אדום, ניתוח חודשי ושבועי, זיהוי דפוסים ודשבורד עם גרפים.

**הכל רץ בתוך Google Sheets בדפדפן. לא מתקינים כלום על המחשב** – גם לא Python.
את ה-PDF של כאל מעלים ישירות לחלון בתוך Sheets, והוא מפוענח בדפדפן עצמו.

---

## התקנה חד-פעמית (כ-10 דקות, הכל בדפדפן)

1. **יוצרים קובץ Sheets חדש:** נכנסים ל-<https://sheets.new> (רצוי בחשבון Gmail אישי) ומשנים את שם הקובץ ל"ניהול הוצאות".
2. **פותחים את עורך הקוד:** בתפריט העליון **תוספים ← Apps Script** (Extensions ← Apps Script).
3. **מדביקים את הקוד** – שלושה קבצים מתיקיית [`dist`](dist):
   | בעורך Apps Script | מה מדביקים |
   | --- | --- |
   | הקובץ הקיים `Code.gs` – מוחקים את כל מה שבו | את כל התוכן של [`dist/Code.gs`](dist/Code.gs) |
   | ➕ ← HTML ← שם: `Import` (בדיוק כך, בלי `.html`) | את כל התוכן של [`dist/Import.html`](dist/Import.html) |
   | ➕ ← HTML ← שם: `Review` | את כל התוכן של [`dist/Review.html`](dist/Review.html) |

   טיפ: ב-GitHub, בכל קובץ יש כפתור "Copy raw file" (סמל של שני ריבועים) שמעתיק את כל התוכן בלחיצה.
4. **אזור זמן:** בעורך, ⚙️ **הגדרות הפרויקט** ← אזור זמן ← `(GMT+02:00) Jerusalem`.
5. **שומרים** (Ctrl+S), חוזרים ללשונית של ה-Sheets ומרעננים את הדף (F5).
6. אחרי כמה שניות מופיע תפריט חדש **"ניהול הוצאות"** ← **הגדרה ראשונית**.
   - Google תבקש אישור הרשאות. מכיוון שזה קוד שלכם ולא אפליקציה מפורסמת, תופיע אזהרה "Google לא אימתה את האפליקציה" ← **מתקדם** ← **מעבר אל ניהול הוצאות (לא בטוח)** ← **אישור**.
   - ההגדרה יוצרת את כל הגיליונות ושתי תיקיות ב-Google Drive: `הוצאות – קבצים חדשים` ו-`הוצאות – קבצים שעובדו`.

## ייבוא ראשון – ההיסטוריה

תפריט **ניהול הוצאות ← ⟳ עדכן הכל** ← גוררים לחלון את הקובץ `transactions_dec25-jul26.csv` (או את קבצי ה-PDF של כאל) ← **התחל**.

בסוף מופיעה הודעה: "יובאו X עסקאות, Y מחכות לסיווג שלך" ← **לסיווג עכשיו** פותח את סרגל הצד.

## כל חודש

1. מורידים מאתר כאל את דף הפירוט כ-PDF (דף לכל כרטיס).
2. ב-Sheets: **ניהול הוצאות ← ⟳ עדכן הכל** ← גוררים את קבצי ה-PDF ← **התחל**.
   (אפשר גם לשים אותם קודם בתיקיית Drive `הוצאות – קבצים חדשים`, והם ייקלטו משם.)
3. החלון בודק לכל קובץ שסכום העסקאות תואם ל"סה"כ" שבדף (✓). קובץ שלא תואם **לא מיובא** אוטומטית.
4. עונים בסרגל הצד על העסקאות הלא-ברורות ← הדשבורד מתעדכן.

## ישראכרט

באתר או באפליקציה של ישראכרט ← פירוט עסקאות ← **ייצוא לאקסל**. גוררים את קובץ האקסל לחלון "עדכן הכל", כמו PDF של כאל.
- עסקאות "שטרם נקלטו" לא מיובאות, כי הן עוד לא סופיות. הן ייכנסו כשיופיעו בקובץ של החודש הבא.
- מותר לייבא שוב קובץ מעודכן של אותו חודש: עסקאות שכבר קיימות (לפי מספר השובר) מדולגות.

## הוצאות קבועות (שכירות וכו')

הוצאות שיורדות ישירות מהבנק: תפריט **ניהול הוצאות ← הוצאות קבועות**, שורה לכל הוצאה (שם, קטגוריה, סכום, יום בחודש, החל מחודש). בכל עדכון ניתוח נוספת עסקה לכל חודש שחסר.

## אם ייבוא PDF נכשל

הפענוח של ה-PDF נבנה לפי המבנה של דפי כאל, אבל **לא נבדק עדיין על דף אמיתי** (נבדק על דף לדוגמה שנבנה בצורה דומה).
אם מופיע ✗ או שהעסקאות לא נקראו נכון: לוחצים על **"טקסט שחולץ"** בשורת הקובץ, מעתיקים את הטקסט (אפשר למחוק ממנו פרטים אישיים) ושולחים אותו ל-Claude כדי לתקן.
בינתיים אפשר לתקן ידנית את מספר הכרטיס ומועד החיוב בחלון, לסמן "ייבא בכל זאת" וללחוץ "ייבא את המסומנים".

## למפתחים

- הקוד המקורי ב-`src/`. אחרי שינוי מריצים `./build.sh`, והוא בונה את שלושת הקבצים שב-`dist/`.
- בדיקות: `node test/parser.test.js` ו-`node test/cal-glyph.test.js` (פענוח; השני מחקה את מבנה דף כאל האמיתי – תו לכל פריט), `node test/e2e.test.js` (ייבוא, סיווג, ניתוח ודשבורד על סביבת דמה של Apps Script), `node test/pdf.test.js` (PDF אמיתי דרך pdf.js – דורש playwright ו-pdfjs-dist@3.11.174).
- **אסור להכניס לגיט קבצי פירוט אשראי (pdf/csv)** – ראו `.gitignore`.
